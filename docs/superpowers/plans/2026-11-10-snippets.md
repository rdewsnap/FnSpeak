# Snippets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Say a trigger phrase while dictating and get saved text in its place, with personal snippets stored locally and team snippets shared through the FnSpeak server.

**Architecture:** A new `snippets` module in `fnspeak-core` holds a SQLite store and a pure matcher. `Pipeline::clean` finds triggers in the filtered transcript, protects them through the cleanup model, and expands them only in `DictationResult::insert`. The server gets a `team_snippets` table and routes modelled on the glossary; the Mac app gets a Snippets settings tab and a sync step that pulls team snippets into the core store.

**Tech Stack:** Rust (rusqlite, thiserror, axum, UniFFI 0.32), Swift/SwiftUI (macOS 14+), SQLite and Postgres migrations.

**Spec:** `docs/superpowers/specs/2026-11-10-snippets-design.md`

## Global Constraints

- Run every cargo command with the rustup toolchain first on PATH: `PATH="$HOME/.cargo/bin:$PATH" cargo …`. Homebrew's older `rustc` otherwise wins and the build fails with "rustc 1.87.0 is not supported".
- No new crate dependencies. Local ids come from SQLite's `randomblob`.
- Trigger: 1 to 60 characters, at least two words. Snippet text: 1 to 4000 characters, not blank.
- A trigger key is lowercase words joined by single spaces, where a word is a run of letters, digits, `'` and `-`. The core (`vocab::learn::heard_key`) and the server (`snippets::phrase_key`) must agree on this.
- Never name a SQL column `trigger`; it is a keyword. Core columns are `trigger_text`, `trigger_key`, `body`. Server columns are `phrase`, `phrase_key`, `body`. JSON and Rust/Swift fields stay `trigger` and `text`.
- Only `DictationResult::insert` is expanded. `raw`, `filtered` and `text` keep the trigger as spoken.
- No expansion in `CleanupMode::Raw` or in `transcribe_verbatim`.
- Snippet text is never logged, on the server or in the app.
- Commit messages: imperative sentence case, no prefix (match `git log`: "Join teams and pull the shared glossary").
- Baseline before starting: `PATH="$HOME/.cargo/bin:$PATH" cargo test -p fnspeak-core -p fnspeak-server` passes (96 core tests, 36 server tests).

```rust
/// Triggers in `text`, in order. Words are compared lowercase and whatever
/// sits between them is ignored, so "My calendar, link" matches "my
/// calendar link". The longest trigger wins where two could start at the
/// same word; of two equally long, the earlier snippet in the slice wins.
pub fn find(text: &str, snippets: &[Snippet]) -> Vec<Match> {
    let spans = word_spans(text);
    let words: Vec<String> = spans.iter().map(|&(s, e)| text[s..e].to_lowercase()).collect();
    let mut keys: Vec<(usize, Vec<&str>)> = snippets
        .iter()
        .enumerate()
        .map(|(i, s)| (i, s.trigger_key.split(' ').filter(|w| !w.is_empty()).collect::<Vec<_>>()))
        .filter(|(_, key)| !key.is_empty())
        .collect();
    // A stable sort keeps slice order among triggers of the same length.
    keys.sort_by(|a, b| b.1.len().cmp(&a.1.len()));

    let mut matches = Vec::new();
    let mut i = 0;
    while i < words.len() {
        let hit = keys
            .iter()
            .find(|(_, key)| i + key.len() <= words.len() && key.iter().zip(&words[i..]).all(|(k, w)| *k == w.as_str()));
        match hit {
            Some((snippet, key)) => {
                matches.push(Match { start: spans[i].0, end: spans[i + key.len() - 1].1, snippet: *snippet });
                i += key.len();
            }
            None => i += 1,
        }
    }
    matches
}

fn is_punctuation(c: char) -> bool {
    matches!(c, '.' | ',' | '!' | '?' | ';' | ':')
}

/// Replace every trigger in `text` with its snippet's text. Returns the new
/// text and the byte ranges the snippet texts occupy in it.
pub fn expand(text: &str, snippets: &[Snippet]) -> (String, Vec<Range<usize>>) {
    let mut out = String::with_capacity(text.len());
    let mut ranges = Vec::new();
    let mut cursor = 0;
    for m in find(text, snippets) {
        out.push_str(&text[cursor..m.start]);
        let body = snippets[m.snippet].text.as_str();
        let start = out.len();
        out.push_str(body);
        ranges.push(start..out.len());
        cursor = m.end;
        // Text that ends its own sentence or line shouldn't get the
        // dictation's punctuation after it: "Thanks,\nRyan\n" then ".".
        if body.chars().next_back().is_some_and(|c| c == '\n' || is_punctuation(c)) {
            if let Some(c) = text[cursor..].chars().next().filter(|c| is_punctuation(*c)) {
                cursor += c.len_utf8();
            }
        }
    }
    out.push_str(&text[cursor..]);
    (out, ranges)
}
```

pub use crate::vocab::learn::heard_key as trigger_key;
pub use matcher::{expand, find, Match};

use crate::commands::is_command_phrase;
use crate::vocab::learn::is_common_phrase;
use rusqlite::{params, Connection};
use std::collections::HashSet;
use std::path::Path;
use std::time::{SystemTime, UNIX_EPOCH};

pub const MAX_TRIGGER_CHARS: usize = 60;
pub const MAX_TEXT_CHARS: usize = 4000;

/// Why a trigger was turned down. The message is shown to the user as is.
#[derive(Clone, Debug, PartialEq, Eq, thiserror::Error)]
pub enum TriggerError {
    #[error("Triggers are 1 to 60 characters.")]
    Length,
    #[error("Use at least two words, so it doesn't fire by accident.")]
    TooShort,
    #[error("\"{0}\" is already a spoken command.")]
    Command(String),
    #[error("That's an everyday phrase and would fire by accident. Pick something more distinctive.")]
    Common,
    #[error("You already have a snippet with that trigger.")]
    Duplicate,
}

#[derive(Debug, thiserror::Error)]
pub enum SnippetError {
    #[error("snippets database error: {0}")]
    Db(#[from] rusqlite::Error),
    #[error(transparent)]
    Trigger(#[from] TriggerError),
    #[error("Snippet text is 1 to 4000 characters.")]
    TextLength,
    #[error("no such snippet")]
    NotFound,
}

pub type Result<T> = std::result::Result<T, SnippetError>;

/// The rules that don't need the store: length, two words, not a spoken
/// command, not an everyday phrase. Returns the trigger's key.
pub fn check_trigger(trigger: &str) -> std::result::Result<String, TriggerError> {
    let chars = trigger.trim().chars().count();
    if chars == 0 || chars > MAX_TRIGGER_CHARS {
        return Err(TriggerError::Length);
    }
    let key = trigger_key(trigger);
    if key.split(' ').filter(|w| !w.is_empty()).count() < 2 {
        return Err(TriggerError::TooShort);
    }
    if is_command_phrase(&key) {
        return Err(TriggerError::Command(key));
    }
    if is_common_phrase(&key) {
        return Err(TriggerError::Common);
    }
    Ok(key)
}

fn check_text(text: &str) -> Result<()> {
    if text.trim().is_empty() || text.chars().count() > MAX_TEXT_CHARS {
        return Err(SnippetError::TextLength);
    }
    Ok(())
}

/// A team snippet as the server sent it.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct TeamSnippet {
    pub id: String,
    pub trigger: String,
    pub text: String,
    pub team_id: String,
    pub team_name: String,
    pub can_edit: bool,
    pub updated_at: i64,
}

pub struct SnippetStore {
    conn: Connection,
}

const COLUMNS: &str = "id, trigger_text, trigger_key, body, source, team_id, team_name, can_edit, updated_at";

impl SnippetStore {
    pub fn open(path: impl AsRef<Path>) -> Result<Self> {
        Self::init(Connection::open(path)?)
    }

    pub fn in_memory() -> Result<Self> {
        Self::init(Connection::open_in_memory()?)
    }

    fn init(conn: Connection) -> Result<Self> {
        conn.execute_batch(
            "PRAGMA journal_mode = WAL;
             CREATE TABLE IF NOT EXISTS snippets (
                 id           TEXT PRIMARY KEY,
                 trigger_text TEXT NOT NULL,
                 trigger_key  TEXT NOT NULL,
                 body         TEXT NOT NULL,
                 -- 'personal' or 'team'
                 source       TEXT NOT NULL,
                 team_id      TEXT,
                 team_name    TEXT,
                 can_edit     INTEGER NOT NULL DEFAULT 1,
                 updated_at   INTEGER NOT NULL
             );
             CREATE UNIQUE INDEX IF NOT EXISTS snippets_personal_key
                 ON snippets (trigger_key) WHERE source = 'personal';",
        )?;
        Ok(SnippetStore { conn })
    }

    fn query(&self, filter: &str, order: &str, args: &[&dyn rusqlite::ToSql]) -> Result<Vec<Snippet>> {
        let mut stmt = self.conn.prepare(&format!("SELECT {COLUMNS} FROM snippets WHERE {filter} ORDER BY {order}"))?;
        let rows = stmt.query_map(args, |r| {
            let source: String = r.get(4)?;
            Ok(Snippet {
                id: r.get(0)?,
                trigger: r.get(1)?,
                trigger_key: r.get(2)?,
                text: r.get(3)?,
                source: if source == "team" { SnippetSource::Team } else { SnippetSource::Personal },
                team_id: r.get(5)?,
                team_name: r.get(6)?,
                can_edit: r.get(7)?,
                updated_at: r.get(8)?,
            })
        })?;
        Ok(rows.collect::<std::result::Result<_, _>>()?)
    }

    /// Every snippet, personal first, then by trigger.
    pub fn list(&self) -> Result<Vec<Snippet>> {
        self.query("1", "source = 'personal' DESC, trigger_key, id", &[])
    }

    /// The snippets that fire: personal ones, plus team ones whose trigger
    /// no personal snippet has. Of two teams' snippets with the same
    /// trigger, the one with the lower id.
    pub fn active(&self) -> Result<Vec<Snippet>> {
        let mut seen = HashSet::new();
        let all = self.query("1", "source = 'personal' DESC, id", &[])?;
        Ok(all.into_iter().filter(|s| seen.insert(s.trigger_key.clone())).collect())
    }

    fn personal(&self, id: &str) -> Result<Snippet> {
        self.query("id = ?1 AND source = 'personal'", "id", &[&id])?.pop().ok_or(SnippetError::NotFound)
    }

    /// Check a trigger for a personal snippet, including that no other
    /// personal snippet has it. `ignoring_id` is the snippet being edited.
    pub fn validate_trigger(&self, trigger: &str, ignoring_id: Option<&str>) -> Result<String> {
        let key = check_trigger(trigger)?;
        let taken: bool = self.conn.query_row(
            "SELECT EXISTS (SELECT 1 FROM snippets WHERE source = 'personal' AND trigger_key = ?1 AND id IS NOT ?2)",
            params![key, ignoring_id],
            |r| r.get(0),
        )?;
        if taken {
            return Err(TriggerError::Duplicate.into());
        }
        Ok(key)
    }

    pub fn add(&mut self, trigger: &str, text: &str) -> Result<Snippet> {
        let key = self.validate_trigger(trigger, None)?;
        check_text(text)?;
        let id: String = self.conn.query_row("SELECT lower(hex(randomblob(16)))", [], |r| r.get(0))?;
        self.conn.execute(
            "INSERT INTO snippets (id, trigger_text, trigger_key, body, source, can_edit, updated_at)
             VALUES (?1, ?2, ?3, ?4, 'personal', 1, ?5)",
            params![id, trigger.trim(), key, text, now_ms()],
        )?;
        self.personal(&id)
    }

    pub fn update(&mut self, id: &str, trigger: &str, text: &str) -> Result<Snippet> {
        self.personal(id)?;
        let key = self.validate_trigger(trigger, Some(id))?;
        check_text(text)?;
        self.conn.execute(
            "UPDATE snippets SET trigger_text = ?2, trigger_key = ?3, body = ?4, updated_at = ?5 WHERE id = ?1",
            params![id, trigger.trim(), key, text, now_ms()],
        )?;
        self.personal(id)
    }

    /// Remove a personal snippet. Team snippets go when the server drops them.
    pub fn remove(&mut self, id: &str) -> Result<bool> {
        Ok(self.conn.execute("DELETE FROM snippets WHERE id = ?1 AND source = 'personal'", [id])? > 0)
    }

    /// Replace every team snippet with what the server has now.
    pub fn replace_team(&mut self, snippets: Vec<TeamSnippet>) -> Result<usize> {
        let tx = self.conn.transaction()?;
        tx.execute("DELETE FROM snippets WHERE source = 'team'", [])?;
        let mut added = 0;
        for s in snippets {
            let key = trigger_key(&s.trigger);
            if key.is_empty() || s.text.is_empty() {
                continue;
            }
            added += tx.execute(
                "INSERT OR REPLACE INTO snippets (id, trigger_text, trigger_key, body, source, team_id, team_name, can_edit, updated_at)
                 VALUES (?1, ?2, ?3, ?4, 'team', ?5, ?6, ?7, ?8)",
                params![s.id, s.trigger, key, s.text, s.team_id, s.team_name, s.can_edit, s.updated_at],
            )?;
        }
        tx.commit()?;
        Ok(added)
    }
}

fn now_ms() -> i64 {
    SystemTime::now().duration_since(UNIX_EPOCH).map(|d| d.as_millis() as i64).unwrap_or(0)
}

    Snippet {
        id: s.id,
        trigger: s.trigger,
        text: s.text,
        team: s.source == SnippetSource::Team,

    fn with_snippets<T>(&self, work: impl FnOnce(&mut SnippetStore) -> Result<T, SnippetError>) -> Result<T, FnSpeakError> {
        let mut p = self.pipeline.lock().unwrap();
        let store = p.snippets.as_mut().ok_or_else(|| FnSpeakError::Storage("Snippets are unavailable.".into()))?;
        work(store).map_err(storage_err)
    }
}

#[uniffi::export]
impl FnSpeakEngine {
    /// Every snippet, the user's own first.
    pub fn snippets(&self) -> Result<Vec<Snippet>, FnSpeakError> {
        self.with_snippets(|store| {
            let all = store.list()?;
            let mine: std::collections::HashSet<String> =
                all.iter().filter(|s| s.source == SnippetSource::Personal).map(|s| s.trigger_key.clone()).collect();
            Ok(all
                .into_iter()
                .map(|s| {
                    let shadowed = s.source == SnippetSource::Team && mine.contains(&s.trigger_key);
                    snippet_record(s, shadowed)
                })
                .collect())
        })
    }

    pub fn add_snippet(&self, trigger: String, text: String) -> Result<Snippet, FnSpeakError> {
        self.with_snippets(|store| store.add(&trigger, &text)).map(|s| snippet_record(s, false))
    }

    pub fn update_snippet(&self, id: String, trigger: String, text: String) -> Result<Snippet, FnSpeakError> {
        self.with_snippets(|store| store.update(&id, &trigger, &text)).map(|s| snippet_record(s, false))
    }

    pub fn remove_snippet(&self, id: String) -> Result<bool, FnSpeakError> {
        self.with_snippets(|store| store.remove(&id))
    }

    /// Replace every team snippet with what the server has now.
    pub fn replace_team_snippets(&self, snippets: Vec<TeamSnippetInput>) -> Result<u32, FnSpeakError> {
        let snippets = snippets
            .into_iter()
            .map(|s| snippets::TeamSnippet {
                id: s.id,
                trigger: s.trigger,
                text: s.text,
                team_id: s.team_id,
                team_name: s.team_name,
                can_edit: s.can_edit,
                updated_at: s.updated_at,
            })
            .collect();
        self.with_snippets(|store| store.replace_team(snippets)).map(|n| n as u32)
    }

    /// Why `trigger` can't be used for a personal snippet, or `None` if it
    /// can. `ignoring_id` is the snippet being edited.
    pub fn validate_snippet_trigger(&self, trigger: String, ignoring_id: Option<String>) -> Option<String> {
        self.with_snippets(|store| store.validate_trigger(&trigger, ignoring_id.as_deref())).err().map(|e| e.to_string())
    }
}

```rust
//! Team snippets: trigger phrases that expand to saved text in every
//! member's dictations. Any member can add one; admins, or whoever added
//! it, can change or remove it. Snippet text is never logged.

use axum::extract::{Path, State};
use axum::http::StatusCode;
use axum::Json;
use serde::Deserialize;
use serde_json::{json, Value};

use crate::args;
use crate::auth::AuthUser;
use crate::db::{new_id, now_ms, Db, Row};
use crate::error::{ApiError, ApiResult};
use crate::teams::{role_in, Role};
use crate::AppState;

const MAX_TRIGGER_CHARS: usize = 60;
const MAX_TEXT_CHARS: usize = 4000;
/// The app's spoken commands. A trigger can't be one of them.
const COMMAND_PHRASES: &[&str] = &["scratch that", "new paragraph", "new line", "send it", "send that"];

const COLS: &str = "s.id, s.team_id, t.name, s.phrase, s.body, u.email, s.added_by, s.created_at, s.updated_at, m.role";
/// `$1` is the caller, whose membership both limits what they see and
/// gives their role for `can_edit`.
const FROM: &str = "FROM team_snippets s
     JOIN teams t ON t.id = s.team_id
     JOIN memberships m ON m.team_id = s.team_id AND m.user_id = $1
     LEFT JOIN users u ON u.id = s.added_by";

fn snippet_json(r: &Row, user_id: &str) -> ApiResult<Value> {
    let can_edit = Role::parse(&r.text(9))? >= Role::Admin || r.opt_text(6).as_deref() == Some(user_id);
    Ok(json!({
        "id": r.text(0),
        "team_id": r.text(1),
        "team_name": r.text(2),
        "trigger": r.text(3),
        "text": r.text(4),
        "added_by": r.opt_text(5),
        "can_edit": can_edit,
        "created_at": r.int(7),
        "updated_at": r.int(8),
    }))
}

/// Lowercase words joined by single spaces, where a word is a run of
/// letters, digits, apostrophes and hyphens. Must match the app's
/// `fnspeak_core::vocab::learn::heard_key`.
pub fn phrase_key(s: &str) -> String {
    s.split(|c: char| !(c.is_alphanumeric() || c == '\'' || c == '-'))
        .filter(|w| !w.is_empty())
        .map(str::to_lowercase)
        .collect::<Vec<_>>()
        .join(" ")
}

/// The trigger with its whitespace collapsed, and its key.
fn clean_trigger(raw: &str) -> ApiResult<(String, String)> {
    let phrase = raw.split_whitespace().collect::<Vec<_>>().join(" ");
    if phrase.is_empty() || phrase.chars().count() > MAX_TRIGGER_CHARS {
        return Err(ApiError::bad(format!("triggers must be 1 to {MAX_TRIGGER_CHARS} characters")));
    }
    let key = phrase_key(&phrase);
    if key.split(' ').filter(|w| !w.is_empty()).count() < 2 {
        return Err(ApiError::bad("a trigger needs at least two words"));
    }
    if COMMAND_PHRASES.contains(&key.as_str()) {
        return Err(ApiError::bad(format!("\"{key}\" is a spoken command")));
    }
    Ok((phrase, key))
}

fn check_text(text: &str) -> ApiResult<()> {
    if text.trim().is_empty() || text.chars().count() > MAX_TEXT_CHARS {
        return Err(ApiError::bad(format!("snippet text must be 1 to {MAX_TEXT_CHARS} characters")));
    }
    Ok(())
}

fn taken() -> ApiError {
    ApiError::Conflict("this team already has a snippet with that trigger".into())
}

async fn fetch(db: &Db, user_id: &str, snippet_id: &str) -> ApiResult<Value> {
    let row = db
        .query_opt(&format!("SELECT {COLS} {FROM} WHERE s.id = $2"), args![user_id, snippet_id])
        .await?
        .ok_or(ApiError::NotFound)?;
    snippet_json(&row, user_id)
}

/// `GET /v1/teams/{id}/snippets`
pub async fn list(State(state): State<AppState>, user: AuthUser, Path(team_id): Path<String>) -> ApiResult<Json<Value>> {
    role_in(&state.db, &team_id, &user.user_id).await?;
    let rows = state
        .db
        .query(
            &format!("SELECT {COLS} {FROM} WHERE s.team_id = $2 ORDER BY s.phrase_key, s.id"),
            args![&user.user_id, &team_id],
        )
        .await?;
    let snippets = rows.iter().map(|r| snippet_json(r, &user.user_id)).collect::<ApiResult<Vec<_>>>()?;
    Ok(Json(json!({ "snippets": snippets })))
}

/// `GET /v1/snippets`: snippets from every team the caller is on, which is
/// what the app pulls.
pub async fn mine(State(state): State<AppState>, user: AuthUser) -> ApiResult<Json<Value>> {
    let rows = state
        .db
        .query(&format!("SELECT {COLS} {FROM} ORDER BY s.phrase_key, s.id"), args![&user.user_id])
        .await?;
    let snippets = rows.iter().map(|r| snippet_json(r, &user.user_id)).collect::<ApiResult<Vec<_>>>()?;
    Ok(Json(json!({ "snippets": snippets })))
}

#[derive(Deserialize)]
pub struct NewSnippet {
    trigger: String,
    text: String,
}

/// `POST /v1/teams/{id}/snippets` with `{"trigger": ..., "text": ...}`.
pub async fn add(
    State(state): State<AppState>,
    user: AuthUser,
    Path(team_id): Path<String>,
    Json(req): Json<NewSnippet>,
) -> ApiResult<(StatusCode, Json<Value>)> {
    role_in(&state.db, &team_id, &user.user_id).await?;
    let (phrase, key) = clean_trigger(&req.trigger)?;
    check_text(&req.text)?;
    let id = new_id();
    let now = now_ms();
    let inserted = state
        .db
        .execute(
            "INSERT INTO team_snippets (id, team_id, phrase, phrase_key, body, added_by, created_at, updated_at)
             VALUES ($1, $2, $3, $4, $5, $6, $7, $8)",
            args![&id, &team_id, &phrase, &key, &req.text, &user.user_id, now, now],
        )
        .await;
    match inserted {
        Ok(_) => {}
        Err(e) if e.is_unique_violation() => return Err(taken()),
        Err(e) => return Err(e.into()),
    }
    Ok((StatusCode::CREATED, Json(fetch(&state.db, &user.user_id, &id).await?)))
}

/// The row's `added_by`, phrase and body, if the caller may change it.
async fn editable(db: &Db, team_id: &str, snippet_id: &str, user_id: &str) -> ApiResult<Row> {
    let role = role_in(db, team_id, user_id).await?;
    let row = db
        .query_opt("SELECT added_by, phrase, body FROM team_snippets WHERE id = $1 AND team_id = $2", args![snippet_id, team_id])
        .await?
        .ok_or(ApiError::NotFound)?;
    if role < Role::Admin && row.opt_text(0).as_deref() != Some(user_id) {
        return Err(ApiError::forbidden("only admins or whoever added a snippet can change or remove it"));
    }
    Ok(row)
}

#[derive(Deserialize)]
pub struct EditSnippet {
    #[serde(default)]
    trigger: Option<String>,
    #[serde(default)]
    text: Option<String>,
}

/// `PATCH /v1/teams/{id}/snippets/{snippet_id}` with `trigger`, `text` or both.
pub async fn update(
    State(state): State<AppState>,
    user: AuthUser,
    Path((team_id, snippet_id)): Path<(String, String)>,
    Json(req): Json<EditSnippet>,
) -> ApiResult<Json<Value>> {
    let row = editable(&state.db, &team_id, &snippet_id, &user.user_id).await?;
    let (phrase, key) = clean_trigger(&req.trigger.unwrap_or_else(|| row.text(1)))?;
    let body = req.text.unwrap_or_else(|| row.text(2));
    check_text(&body)?;
    let updated = state
        .db
        .execute(
            "UPDATE team_snippets SET phrase = $2, phrase_key = $3, body = $4, updated_at = $5 WHERE id = $1",
            args![&snippet_id, &phrase, &key, &body, now_ms()],
        )
        .await;
    match updated {
        Ok(_) => {}
        Err(e) if e.is_unique_violation() => return Err(taken()),
        Err(e) => return Err(e.into()),
    }
    Ok(Json(fetch(&state.db, &user.user_id, &snippet_id).await?))
}

/// `DELETE /v1/teams/{id}/snippets/{snippet_id}`
pub async fn remove(
    State(state): State<AppState>,
    user: AuthUser,
    Path((team_id, snippet_id)): Path<(String, String)>,
) -> ApiResult<StatusCode> {
    editable(&state.db, &team_id, &snippet_id, &user.user_id).await?;
    state.db.execute("DELETE FROM team_snippets WHERE id = $1", args![&snippet_id]).await?;
    Ok(StatusCode::NO_CONTENT)
}

        guard let engine else { return completion("FnSpeak is still loading.") }
        queue.async {
            var problem: String?
            do {
                if let id {
                    _ = try engine.updateSnippet(id: id, trigger: trigger, text: text)
                } else {
                    _ = try engine.addSnippet(trigger: trigger, text: text)
                }
            } catch {
                problem = error.localizedDescription
            }
            DispatchQueue.main.async { completion(problem) }
        }
    }

    func removeSnippet(id: String, completion: @escaping () -> Void) {
        guard let engine else { return completion() }
        queue.async {
            _ = try? engine.removeSnippet(id: id)
            DispatchQueue.main.async { completion() }
        }
    }

    /// Why `trigger` can't be used for a personal snippet, or nil if it can.
    func snippetTriggerProblem(_ trigger: String, ignoring id: String?, completion: @escaping (String?) -> Void) {
        guard let engine else { return completion(nil) }
        queue.async {
            let problem = engine.validateSnippetTrigger(trigger: trigger, ignoringId: id)
            DispatchQueue.main.async { completion(problem) }
        }
    }
```

If `error.localizedDescription` shows a generic "operation couldn't be completed" string for a `FnSpeakError`, look at how `EngineController.load()` turns the same error type into `status = .failed(error.localizedDescription)`; use whatever that path relies on (the generated error type conforms to `LocalizedError` when it does).

import SwiftUI

/// Settings → Snippets: trigger phrases that expand to saved text. The
/// user's own are edited here; team snippets come from sync.
struct SnippetsTab: View {
    @ObservedObject var engine: EngineController
    @ObservedObject private var account = AccountController.shared
    @ObservedObject private var sync = SyncEngine.shared
    @State private var snippets: [Snippet] = []
    @State private var draft: SnippetDraft?

    private var personal: [Snippet] { snippets.filter { !$0.team } }
    private var fromTeams: [Snippet] { snippets.filter(\.team) }

    var body: some View {
        VStack(alignment: .leading, spacing: 10) {
            HStack(alignment: .firstTextBaseline) {
                Text("Say a snippet's trigger while dictating and its text is typed in its place.")
                    .font(.callout).foregroundStyle(.secondary)
                Spacer()
                Button("New Snippet") { draft = SnippetDraft() }
            }

            List {
                Section("Yours") {
                    if personal.isEmpty {
                        Text("No snippets yet. Try a trigger like “my calendar link”.").foregroundStyle(.secondary)
                    }
                    ForEach(personal, id: \.id) { snippet in
                        row(snippet) {
                            Button("Edit…") { draft = SnippetDraft(snippet) }
                            if account.isSignedIn, !account.sharedTeams.isEmpty {
                                Menu("Share with") {
                                    ForEach(account.sharedTeams) { team in
                                        Button(team.name) { account.shareSnippet(snippet, with: team) }
                                    }
                                }
                            }
                            Divider()
                            Button("Delete", role: .destructive) { engine.removeSnippet(id: snippet.id, completion: reload) }
                        }
                    }
                }
                if !fromTeams.isEmpty {
                    Section("From your teams") {
                        ForEach(fromTeams, id: \.id) { snippet in
                            row(snippet) {
                                if snippet.canEdit {
                                    Button("Edit…") { draft = SnippetDraft(snippet) }
                                    Button("Remove from \(snippet.teamName ?? "team")", role: .destructive) {
                                        account.removeTeamSnippet(snippet)
                                    }
                                } else {
                                    Text("Only its author or a team admin can change this")
                                }
                            }
                        }
                    }
                }
            }

            if let message = account.error ?? account.notice {
                Text(message).font(.callout).foregroundStyle(account.error == nil ? Color.secondary : Color.orange)
            }
        }
        .padding()
        .onAppear(perform: reload)
        .onChange(of: sync.snippetsRevision) { reload() }
        .sheet(item: $draft) { draft in
            SnippetEditor(draft: draft, engine: engine, saved: reload)
        }
    }

    private func row<Items: View>(_ snippet: Snippet, @ViewBuilder menu: () -> Items) -> some View {
        HStack(alignment: .firstTextBaseline) {
            VStack(alignment: .leading, spacing: 2) {
                Text(snippet.trigger)
                Text(snippet.text.split(separator: "\n", omittingEmptySubsequences: true).first.map(String.init) ?? "")
                    .font(.callout).foregroundStyle(.secondary).lineLimit(1)
            }
            Spacer()
            if snippet.team {
                Text(snippet.shadowed ? "Replaced by yours" : (snippet.teamName ?? "Team"))
                    .font(.caption).foregroundStyle(.secondary)
            }
            Menu(content: menu) { Image(systemName: "ellipsis.circle") }
                .menuStyle(.borderlessButton).menuIndicator(.hidden).fixedSize()
                .help("Actions for \(snippet.trigger)")
        }
    }

        engine.snippets { snippets = $0 }
    }
}

/// What the editor sheet is working on: a new snippet, or an existing one.
struct SnippetDraft: Identifiable {
    let id = UUID()
    var snippet: Snippet?
    var trigger = ""
    var text = ""

    init() {}

    init(_ snippet: Snippet) {
        self.snippet = snippet
        trigger = snippet.trigger
        text = snippet.text
    }
}

struct SnippetEditor: View {
    @State var draft: SnippetDraft
    let engine: EngineController
    let saved: () -> Void

    @Environment(\.dismiss) private var dismiss
    @State private var problem: String?

    private var isTeam: Bool { draft.snippet?.team ?? false }
    private var canSave: Bool {
        problem == nil
            && !draft.trigger.trimmingCharacters(in: .whitespaces).isEmpty
            && !draft.text.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty
    }

    var body: some View {
        VStack(alignment: .leading, spacing: 10) {
            Text(draft.snippet == nil ? "New Snippet" : "Edit Snippet").font(.headline)
            TextField("Trigger", text: $draft.trigger, prompt: Text("my calendar link"))
                .onChange(of: draft.trigger) { check() }
            if let problem {
                Text(problem).font(.callout).foregroundStyle(.red)
            } else {
                Text("Two or more words you wouldn't say by accident.").font(.callout).foregroundStyle(.secondary)
            }
            TextEditor(text: $draft.text)
                .font(.body)
                .frame(minHeight: 140)
                .border(.separator)
            HStack {
                Spacer()
                Button("Cancel") { dismiss() }.keyboardShortcut(.cancelAction)
                Button("Save", action: save).keyboardShortcut(.defaultAction).disabled(!canSave)
            }
        }
        .padding()
        .frame(width: 420)
    }

    /// Personal triggers are checked as you type. A team snippet's trigger
    /// is checked by the server on save, since only it knows the team's
    /// others; the server doesn't apply the everyday-phrase rule, so an edit
    /// to a team trigger can get past that one.
    private func check() {
        let trigger = draft.trigger
        guard !isTeam, !trigger.trimmingCharacters(in: .whitespaces).isEmpty else { return problem = nil }
        engine.snippetTriggerProblem(trigger, ignoring: draft.snippet?.id) { message in
            // Ignore the answer to an older keystroke.
            if trigger == draft.trigger { problem = message }
        }
    }

    private func save() {
        if let snippet = draft.snippet, snippet.team {
            AccountController.shared.updateTeamSnippet(snippet, trigger: draft.trigger, text: draft.text)
            return dismiss()
        }
        engine.saveSnippet(id: draft.snippet?.id, trigger: draft.trigger, text: draft.text) { message in
            if let message {
                problem = message
            } else {
                saved()
                dismiss()
            }
        }
    }
}
